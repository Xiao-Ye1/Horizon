## [llama.cpp b9606 Adds EAGLE3 Speculative Decoding Support](https://github.com/ggml-org/llama.cpp/releases/tag/b9606) ⭐️ 8.0/10

The b9606 release of llama.cpp integrates EAGLE3 speculative decoding, a technique that accelerates LLM inference by using a draft model to propose multiple tokens at once. This collaborative open-source contribution enables faster text generation while maintaining output quality. Speculative decoding is a leading method to reduce LLM latency without retraining the target model, and adding EAGLE3 support brings this powerful optimization to the widely used llama.cpp ecosystem, benefiting developers and end-users running local models. EAGLE3 uses extrapolative draft heads attached to the target model's layers, adding only 2–5% overhead while achieving 2–3x speedups. The implementation involved enabling layer input extraction, adding draft model setup, and fixing compatibility issues like multi-sequence handling and Gemma4 support.

github · github-actions[bot] · Jun 12, 08:45

**Background**: Speculative decoding speeds up autoregressive LLMs by using a smaller draft model to predict future tokens, then verifying them with the target model in one pass. EAGLE is an advanced variant that adds lightweight draft heads to the target model itself, avoiding the need for a separate draft model. EAGLE3 further improves this by extrapolating features from the target model's layers, making it more efficient and accurate. llama.cpp is a popular C++ library for running LLMs efficiently on consumer hardware.

## [Transformers v5.12.0 Released: Introducing MiniMax-M3-VL Vision-Language Model](https://github.com/huggingface/transformers/releases/tag/v5.12.0) ⭐️ 8.0/10

Hugging Face Transformers v5.12.0 introduces the MiniMax-M3-VL vision-language model, which features a Mixture-of-Experts decoder and sparse attention for efficient multimodal understanding. The release also adds PP-OCRv6 for lightweight OCR and Parakeet-RNNT for speech recognition. MiniMax-M3-VL integrates advanced architectures directly into the widely-used Transformers library, making cutting-edge vision-language capabilities readily accessible to practitioners. Its MoE and sparse attention enable scalable, efficient processing of long multimodal contexts. The model uses a CLIP-style vision tower with 3D rotary position embeddings, a mixed dense/sparse MoE decoder with SwiGLU-OAI gated experts, and a lightning indexer for block-sparse attention. Images are processed via a Conv3d patch embedding system.

github · vasqu · Jun 12, 14:39

**Background**: Mixture-of-Experts (MoE) is a neural architecture that uses multiple expert subnetworks with a gating mechanism to selectively activate experts, increasing model capacity without proportionally increasing compute. Sparse attention reduces the quadratic complexity of full attention by restricting token interactions to a subset, enabling efficient long-sequence processing. Rotary Position Embeddings encode positional information by rotating query and key vectors in attention, preserving relative distance information. These techniques collectively improve scalability and performance in large models.

It also demonstrates Swift's growing role in low-level systems programming at Apple.
